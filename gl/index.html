    This is an interactive ray/path tracer that runs in your browser. To try it out, choose a scene with the button at the top left, wait for the shader to finish compiling, then enjoy!

    The camera can be moved with WASD/LMB-click-drag, and scene geometry can be selected by clicking on the viewport. Further geometry and material properties of selected objects can be viewed/modified by opening the Edit menu. Geometry can be simply transformed by first clicking to select, then dragging, with the type of transformation selectable in the drop down.

    Objects and lights can be added with the Add button below the view (they appear in front of the camera), and the selected object removed with the Delete button or key. Adding or removing is instant when the scene is loaded with ?worldEditable=true; otherwise the shader is rebuilt, which takes a few seconds.

    For more information on the technical details behind this project, see the github project page.
